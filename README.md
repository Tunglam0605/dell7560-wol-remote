# Dell Precision 7560 — Remote Wake

A static, client-side UI for Wake-on-LAN via MQTT over WSS/TLS. This
repository contains no MQTT usernames, passwords, ESP32 firmware, or
Windows credentials. Connect through your own broker with per-user ACLs.

Run with HTTPS (GitHub Pages) and configure the broker from the UI.
The ESP32 must remain powered and connected to the broker.
